Embedded AI Portfolio

A collection of implementations and experiments related to neural networks and artificial intelligence, with a focus on understanding the underlying algorithms and their application to engineering problems.

The repository is intended to document my work and progressively extend it toward embedded AI applications.

Neural Networks

The NeuralNetworks directory contains MATLAB implementations of neural network training and optimization algorithms developed while studying neural network fundamentals.

Currently included:

* Conjugate Gradient Backpropagation (CGBP)
* Golden Section Search
* Levenberg–Marquardt Backpropagation (LMBP)
* Gauss–Newton Bayesian Regularization (GNBR)
* Regularization
* Real-Time Recurrent Learning (RTRL)

The implementations were developed for educational purposes with emphasis on understanding the algorithms rather than relying exclusively on high-level neural network training functions.

Tools

* MATLAB
* MATLAB Live Scripts

Future Work

The repository will be extended with applications of neural networks to engineering and embedded systems, including model inference and embedded deployment.
