Neural Networks

MATLAB implementations of neural network training algorithms:

* Conjugate Gradient Backpropagation (CGBP)
* Golden Section Search
* Levenberg–Marquardt Backpropagation (LMBP)
* Gauss–Newton Bayesian Regularization (GNBR)
* Regularization
* Real-Time Recurrent Learning (RTRL)

The algorithms were implemented while studying Neural Network Design, with the goal of understanding how neural networks are trained.
